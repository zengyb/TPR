# 抱抱羊文创 · TPR 指令卡

一套可以「听、看、做」的亲子英语动作卡。

TPR（Total Physical Response，全身反应教学法）强调先听懂、再用动作回应。孩子看到卡片上的动作画面，听到英语指令，跟着做动作，在真实的身体体验中理解词汇和句型，而不是先背中文意思。

本 H5 将 100 张 TPR 动作卡做成适合手机和平板使用的交互页面：打开链接即可使用，无需下载 App，也无需注册账号。

## 适合谁

- 2–8 岁处于英语启蒙阶段的孩子
- 希望在家进行亲子英语互动的家长
- 幼儿园、早教机构、英语课堂的律动与指令教学
- 喜欢用卡片、点读、动作游戏进行学习的家庭

## 一套卡片，四个学习层级

每张卡片围绕一个核心动作词，按 L1 → L4 逐层扩展：

| 层级 | 内容 | 学习目标 |
| --- | --- | --- |
| L1 | 核心词 + 中文释义 + 动作图片 | 听懂单词，建立声音与动作的联系 |
| L2 | 1 个基础指令句 | 听懂完整指令并做出动作 |
| L3 | 3 个扩展句 | 替换对象、方式、场景，扩大理解范围 |
| L4 | 3 个进阶句 | 理解顺序、条件、多步骤的连续指令 |

以 `brush` 为例：

- L1：`brush` 刷；刷牙
- L2：`Brush your teeth!` 刷牙！
- L3：`Brush your hair.` / `Brush your teeth slowly.` / `Brush your teeth gently.`
- L4：`Brush your teeth before you eat breakfast.` 等连续指令

## 核心功能

### 100 张主题动作卡

100 个高频动作词，按 5 个生活场景组织，每个场景 20 张：

| 场景 | 内容 |
| --- | --- |
| 生活与自理 Self-care | 刷牙、梳头、穿衣、洗手等 |
| 身体与动作 Body & Movement | 跑、跳、蹲、伸展等 |
| 日常与起居 Daily Routines | 起床、吃饭、洗澡、睡觉等 |
| 游戏与运动 Play & Sports | 抛接、踢球、攀爬、旋转等 |
| 整理与家务 Clean & Organize | 收拾、擦拭、分类、摆放等 |

每个场景有独立主题色，方便快速识别和按场景学习。

### 正反面 3D 翻卡

- **正面**：核心词、中文释义、动作插画、基础指令句。
- **背面**：3 个扩展句和 3 个进阶句，全部配有中文翻译。
- 点击右上角按钮翻转卡片，翻卡动画保留纸质卡片的手感。

### 8 个点读区域

每张卡片有 8 个可点击播放的区域，点击即听：

| 区域 | 内容 |
| --- | --- |
| 单词与图片区域 | 核心词发音 |
| 正面例句区域 | 基础指令句 |
| 背面扩展句式 1–3 | 3 个扩展句 |
| 背面进阶句式 1–3 | 3 个进阶句 |

播放时对应区域显示主题色高亮和圆形进度，同一时间只播放一个音频，再次点击可停止。

### 手势切换卡片

- 左右滑动切换上一张 / 下一张。
- 底部圆点提示当前位置。
- 切换时保留卡片布局，不出现明显跳动。

### 目录、搜索与场景筛选

- 目录视图按顺序浏览全部 100 个词汇。
- 支持英文单词、中文释义、场景名称搜索。
- 可按 5 个场景快速跳转，也可以回到全部场景。
- 目录中直接点击任意词汇即可回到对应卡片。

### 中英文界面切换

页面标题、按钮、提示语支持中文 / English 切换，方便家长和英语教师使用。

### 为手机阅读设计

- 全屏卡片布局，适配 iOS、微信内置浏览器和 Android。
- 大按钮、大点击区域，适合孩子自己操作。
- 插画与音频预加载，滑动和点读尽量做到即时响应。
- 图片和音频使用浏览器缓存，重复打开时减少等待。

## 使用方式

1. 用手机或平板打开页面链接或扫描二维码。
2. 左右滑动，选择想学习的动作卡。
3. 点击图片、单词或句子，听英语发音。
4. 跟着音频做动作，先做对，再开口说。
5. 点击右上角翻卡，查看更多扩展句和进阶句。
6. 需要查找词汇时，打开目录，使用搜索或场景筛选。

## 内容规模

- 100 个核心动作词
- 100 个基础指令句
- 300 个扩展句
- 300 个进阶句
- 800 条配套英语音频
- 100 张动作插画

所有句子均配有中文翻译，方便家长在亲子互动中理解和使用。

## 技术说明

- React 19 + TypeScript + Vite 6
- Tailwind CSS 4
- Motion 卡片翻转与切换动画
- lucide-react 图标
- 纯静态前端，无后端、无数据库、无账号体系
- 站点部署在 Cloudflare Pages
- 图片与音频存放在 Cloudflare R2，通过独立媒体域名访问
- 音频优先使用 Web Audio 内存播放，并在 iOS、微信等环境中自动回退到 HTMLAudio

## 本地运行

```bash
npm install
npm run dev
```

默认访问地址：`http://localhost:3000`

构建与检查：

```bash
npm run build
npm run lint
```

## 部署

项目通过 GitHub 同步到 Cloudflare Pages：

- 构建命令：`npm run build`
- 输出目录：`dist`
- 页面与构建资源由 Cloudflare Pages 托管
- 图片与音频由 R2 媒体域名 `https://tpr.fastpage.top` 提供

## 项目结构

```text
src/
├── App.tsx                 页面框架、目录、搜索、场景筛选
├── components/
│   └── VocabularyCard.tsx  卡片正面 / 背面、点读区域、翻卡
├── data/
│   ├── vocabulary.ts       100 个词汇、例句、场景与主题色
│   └── mediaMap.ts         图片与音频地址映射
├── hooks/
│   └── useAudioPlayer.ts   播放状态与进度
├── lib/
│   ├── audioManager.ts     音频预加载、解码、缓存与播放
│   └── imagePreloader.ts   图片预加载与重试
└── types.ts                数据类型定义
```

## 内容维护

- 词汇、中文释义、L2 / L3 / L4 例句：`src/data/vocabulary.ts`
- 图片与音频地址：`src/data/mediaMap.ts`
- 场景名称与主题色：`src/data/vocabulary.ts` 顶部的 `SCENES`
- 媒体资源存放在 R2 的 `images/` 与 `audio/` 目录，不进入 Git 仓库

性能优化与媒体缓存配置的细节见 [性能优化迭代记录](docs/性能优化迭代记录.md)。
